# 结构转折候选 v1 与 Watch 图表标记修复

日期：2026-09-22。A/B规则、正式扫描计算和通知链路不变，ACTIVE仍为v25。

## 使用

Watchlist日K工具栏点击「C结构候选」。默认关闭，开启后按需计算当前单股，不写入正式扫描、持仓或提醒。展开「C策略说明与买卖过程」可查看最近8笔覆盖可视区间的候选交易；悬停信号当天K线查看判定依据。切换周/月图不显示日线候选。

## 独立候选逻辑

- 摆动低点需右侧2根K线确认，不将信号回填至最低点。
- 最近45根内出现双底或抬高低点：按14期ATR的0.75倍容忍支撑差异，进入观察。新结构替代旧结构时明确记录旧观察失效。
- 观察之后20根内，收盘收复MA5、突破前日高点且MACD柱改善，才确认买入；入场到失效线距离不超过4ATR。
- 失效线为最新确认摆动低点减0.5ATR。不使用相对旧高点的固定跌幅门槛。
- 确认后收盘跌破结构失效线则模拟退出；收盘低于MA10且MACD动能走弱，首次提示风险，连续两根模拟退出。
- 观察不等于买入，低吸失效不等于持仓卖出，候选退出不是真实成交。

评价以观察→确认→风险→退出的完整过程为单位，提供持有根数、最大有利变动MFE、最大不利变动MAE及未退出状态。信号日收盘仅为研究参考，未计成本、滑点、成交限制；不能据此承诺可实现收益。

## 数据与资源边界

GET /api/v1/watch/structure-candidate?symbol=600641&start_date=2026-08-01&end_date=2026-09-21

固定历史锚点2023-01-01，同版本改变可视开始日不会改变初始化；仅使用截至end_date的行情，不读取未来数据。单次单股最多1500根，日期可视区间最长1095天。数据库mode=ro、query_only、contextlib.closing。返回历史实际起止日期，图表标记过滤至可视范围；交易过程可能跨越可视起点，summary注明含热身范围。无新增后台任务；前端15秒超时、5分钟缓存，关闭开关不发候选请求。

## 标记缺失修复

默认/watch/markers保持该股最新完成历史扫描覆盖区间的规则语义，在覆盖区间外补正式日快照。显式scan_id仅返回扫描。输出来源、版本、扫描覆盖期，按首次状态转折绘制，并读取区间前驱避免冷却重复；跨源不同setup可分别确认。新增INVALIDATED标记，不称为卖出。

600641的最新历史扫描截至2026-08-06；修复后8/12入区、8/17确认、8/19失效均由正式v25日快照显示。候选截至9/21：8/14观察→8/17确认→8/19风险→8/20退出；9/8观察→9/14确认，9/21仍未退出。8月中这一笔是失败样本，8月初最低点没有强行生成信号。

## 局限
