# MRGC 近20日智能分组

分组 `smart_mrgc_20d` 在现有盘后 `structure_monitor` 阶段、同一写库锁内刷新。优先交易日历，窗口内所有 MRGC 必须有成功运行记录和源行情，成员按股票去重。零命中交易日由成功运行记录证明，不以结果行数判断失败。

该池仅接入 C 结构监控，`monitor_enabled=0` 表示不自动开启 A/B 低吸监控。新增 C 信号合入现有单封低吸日报，采用现有通知投递去重和可信门；C 仍为模拟策略信号，不改变 Portfolio 真实仓位。首次基线取实际启用日与数据日的较晚者，仅自动池成员的初始化历史事件被排除。已有人工池事件正常保留。

窗口缺数据或总监控范围超过300只时保留上次成员，展示 BLOCKED，不截断。历史补算不倒退当前成员。自动池禁止手工增删、改名和开启A/B跟踪。名称悬停显示最近命中日和命中次数。
