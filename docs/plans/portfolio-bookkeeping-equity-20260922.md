# Portfolio 记账与权益图改版方案

状态：用户已批准，2026-09-23 已完成实现、隔离入账测试与生产页面验收。

## 用户流程

页面顶部提供「记一笔」「导入截图」。点击后打开右侧抽屉，原主页面的完整手工表单收进抽屉，持仓每行可带「买入/卖出」快捷入口并预填股票。

抽屉有「截图录入」「手工录入」「资金往来」三种方式。截图支持粘贴和多图选择，首版重点兼容华宝/同花顺交割单及银证转账截图。持仓截图仅对账，不能生成虚构买卖。

截图 → 识别草稿 → 按日期时间排序的可编辑表格 → 批量预览 → 确认入账。预览同时显示本次新增、疑似重复、待补字段，及入账后的现金、每股持仓数量。成功回执显示已记入数量、跳过数量和更新后的余额，并保留来源批次。

表格字段：日期、时间、股票名称/代码、买卖方向、实际成交价、成交股数、税费合计、现金收支；每行可打开来源截图定位。缺失/截断字段不猜测；截图只显示税费合计时不虚构佣金和印花税拆分。

## 重复与更正

成交编号优先作为强去重依据。图片重复上传按文件hash识别；重叠截图还需逐行比对。日期/分钟/股票/方向/价格/数量相同只能标疑似重复，不能直接删除同一分钟的多笔真实成交。

已有手工合并记录与多笔券商成交需作为候选更正组，显示冲销旧记录与新增明细的差异，单独明确确认，不自动替换。普通导入不允许悄悄改变期初现金；期初对账基准独立展示且有审计记录。

确认使用服务端草稿版本、账户ledger revision、批次幂等键。整批按真实时间验证资金、持仓和T+1，单次短事务提交；失败整批回滚。不能循环调用会各自commit的单笔API冒充批次原子性。

历史回补必须重建受影响的收益快照并同步退出计划。若行情不完整，明确显示收益待重算，不显示过期快照为新结果；补算按账户串行、日期范围有界，不自动发送历史提醒。

## 权益图

主页面顺序：账户与资产摘要 → 全宽权益图 → 当前持仓 → 提醒与流水。最新快照技术状态移到信息提示，图高桌面约340px、手机约260px。

图表可切换「总资产」「累计盈亏」「收益率」。默认总资产，蓝色细线与浅渐变面积；盈亏图以零轴区分红涨绿跌；收益率由有效每日资金流调整收益连乘，不用资产首尾比替代。无效数据留断点，禁止用平滑曲线制造未观测高低点。

区间提供近1月、近3月、全部；显示真实起止日。短历史账户的「全部」明确写“自8月6日对账起”，不显示成完整年度或开户以来。基准日收盘只作锚点。

入金/出金用离散标记，悬浮显示金额；总资产允许出现真实资金跳变，盈亏和收益率剔除资金进出。Tooltip展示日期、总资产、现金、股票市值、当日盈亏和当日资金流；无需默认在图上叠加所有线。

保留日/周/月摘要；不足全年时用“对账以来”替代含混的“年度完整收益”。原始投入、倒推现金基准和投资收益分开，不把此次2488.76元基准修正当成新入金或已证实利润。

## 识别方案与资源预算

优先试验macOS自带Vision文字识别，使用一次性本地进程，仅在用户上传时运行。用现有5张截图验证中文名称、金额小数点和错行问题；工具可用不等于准确性已经验收。先本地OCR+版面解析+人工核对，不默认外传账户截图或增加大模型常驻服务。手工录入始终可用。

首版上限：每批8张、每张8MB、总32MB、每批200条；超大图片限制解码像素数；识别串行且每张30秒超时。临时图片确认/取消后及时清理，草稿图片24小时过期，清理在请求时有界执行，不新增高频定时器。只保留结构化审计和图片hash；原图长期留存后续按用户需求配置。

目标：闲置无额外进程/轮询，识别并发1，峰值RSS目标低于300MB（实测后报告，超限再降尺寸），图表最多400日数据且复用已有查询，单批写事务目标低于1秒。避免长期写锁、全库复制与无限日志。

## 主要风险与验收

- 正常：现有截图17笔识别/核对，与已入账记录比对后不重复记账。
- 边界：重叠截图、同分钟两笔同价同量成交、跨月日期、省略年份、截断行、空图、多账户。
- 错误：小数点误读、费用缺失、OCR超时、文件伪装、过大图片、资金不足、卖出超量、T+1、提交时账本已变。
- 原子性：批次中间失败、重复点击、网络重试，零重复和零部分提交；更正保留冲正链。
- 图表：20000元入金不计投资盈利，0值/负值/缺价/只有1点等状态有明确展示；范围收益与后端有效收益链一致。
- 正式库不写测试成交；隔离数据库夹具完成happy/edge/error测试，生产只读验收。
- 前端完成后独立NEXT_DIST_DIR预构建与检查，成功后切换生产包；失败回滚。实点记账草稿和图表交互，核对页面/静态资源/API耗时，报告内存/线程/磁盘/请求量。
