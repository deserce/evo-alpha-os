# MRGC研究预设口径（查看策略收益前固定）

研究截止2026-10-30，近期2026-09-28至10-30；历史对照从具备连续20日MRGC成功审计后开始，至2026-09-18。历史对照使用各日已保存候选，而非仅近期135只股票。训练结束与近期开始之间留出隔离，跨期持仓不计入历史对照。

候选规则：每日入选基线；过去5日未入选(new5)；过去20日未入选(first20)；过去5日未入选但6~20日前出现(reentry5)；new5且行业当天至少3只、数量和占比均高于前5日均值(sector_new5)；new5且MA20<收盘<=MA20+1.5ATR14、当日涨幅<5%(controlled_new5)；过去20日入选且当日C买入确认(c_buy)；过去20日入选且当日缠论首次可见买点(chan_buy)。不是8个策略都择优上线，均列全部结果。

主口径：信号日t收盘后生成，t+1开盘买，持有5个完整交易日后开盘卖(t+6)，避免同日收盘成交及T+0。3/10日为预设敏感性。逐股复盘同时列1/3/5/10日开盘到开盘收益。次日缺行情不追补买入；开盘接近涨停跳过；退出开盘接近跌停或无行情则顺延，超出数据末端标未完成。主结果要求已完成持有期，未完成单列。

固定退出以外另测试所有规则的5日上限+收盘跌破入场价-1.5ATR14或出现C_EXIT/C_RISK时次日开盘退出；固定阈值，不按样本搜最优参数。ATR只用信号日及过去行情；同股持仓不叠加。

费用用每笔往返总成本0.4个百分点作主假设（含佣金、税费、滑点的情景值，不代表实际费率），0.2/0.6个百分点敏感性。日线只能近似涨跌停开盘可成交性，复权比例及未复权收盘用于交叉检查，不能验证订单排队或盘中路径。

组合使用5个现金槽位，每次最多投入当时总资产20%，各槽位一只；按信号日RPS250降序、股票代码升序选取，不用未来表现排名；持仓日收盘估值，计算组合回撤与收益。无杠杆；不模拟100/200股整手与最低佣金，定位为规模标准化研究。

胜率用Wilson区间（仍有同行业/同日相关性），同时给信号日聚类bootstrap平均收益区间、平均/中位净收益、盈亏比、尾部损失、最大不利波动、基准超额、资金占用和组合回撤。不把重复入选当独立交易；不把样本内挑选当独立验证；不成熟收益不补零。

C/Chan以当前保存信号作历史重放，另审计下一交易日09:30前存档可见性。当前修订行情与当前保存MRGC不能证明当时真实可得。行业使用本地统一大类并标记来源和历史分类限制。缺失成功运行、坏价/异常跳变、缺失raw的日期明确记录并有界处理。

资源预算：正式库mode=ro/query_only；单计算进程、原生线程1；目标峰值内存<512MB、产物<30MB；记录耗时和峰值内存。不触发采集、邮件、策略配置变更、后台调度或真实交易。

实现核对补充：买卖两边均按入场名义本金计0.2%，逐笔净收益统一为(卖价/买价-0.002)/1.002-1，组合使用同样现金流；允许开盘先卖后买同股但禁止同时叠仓。有限组合直接从原始每日候选选择，不能复用已因独立持仓去重而删除的信号；已选中但行情路径不完整时整条组合成绩作废，不通过事后排除改善收益。
