## 根因与修复

1. 原流程较依赖最新日期，不能证明中间日期或个股覆盖完整。现在按日历逐日核对，并保存未完成依赖。
2. 择时/风控未真正接收历史目标日，风控曾全表替换。现在严格指定日期、事务替换该日，计划键含日期；API 关联也加入日期条件。
3. C/低吸/日报原先没有稳定跟随补数。现在沿用唯一 workflow 锁补齐，历史任务不刷新当前智能池。
4. 旧低吸种子含旧复权价位和不可信触发锚点。等比变化核验后在内存换基；真实修订从可信种子有界预热，只落库目标日。
   002832 从 09-23 可信种子重放 9 日，纠正 10-14 的前态，未修改 10-14 旧行或旧事件。
5. 历史估值曾以 0 表示未知 PE/PB，并使用推算总市值。已清理窗口内 local_kline 占位，真实来源不被兜底覆盖，当前 stock_info 不回写。
6. 抢锁失败前不再截断活动 owner 元数据；超时清理子任务进程组；历史/人工 retry 不唤醒资料下载队列。
