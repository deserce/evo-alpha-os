## 根因

行情和日 K 质量检查已经恢复，但 C 监控仍保留补数前的 BLOCKED 快照。

## 已实施

- 晨间核心计算后执行 C 监控，沿用原互斥锁、任务边界预算和 120 秒非关键任务超时，不运行邮件任务。
- 快照保存实际输入行情的 SHA-256 摘要；GET 只读比较目标日质量与输入内容，不重放选股策略。
- 输入范围限定在已有 C 历史窗口、最多 300 只股票，每只最多 1501 根，逐股处理。
- 修改历史行情、同秒修复和空时间戳都能识别；仅更新时间或追加目标日后的行情不会误报。
- 没有校验摘要的旧版有效快照显示待重新校验，不在 GET 内自动补算。
- Watchlist、个股详情、Strategy 共用中文原因；过期 C 及其同日存档提示不作为当前买卖信号。
